Detailed Description

Native tests for ct_filter.h: the CT1 filter, in fixed point.

The current sample reaches the filter DC-removed, left-aligned (x64 scale, int16). The filter is Robin's (Mk2_fasterControl_Full), with the float maths replaced by fixed point: these tests hold it to his time constant, his output and his dead zone.
