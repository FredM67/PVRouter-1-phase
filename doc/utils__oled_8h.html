Detailed Description

Some utility functions for OLED display.

From Mk2_fasterControl_Full/utils_oled.h: an SSD1306 128x64 OLED on the hardware I2C (A4 SDA, A5 SCL), driven by U8x8 (the text-only part of U8g2: no frame buffer in RAM, the screen is written in 8x8 tiles). The logo at startup, then:

  • rows 0 to 5: the value in large digits, 5 characters (energy "1.234" or "12.34" kWh, temperature " 23.5"), or FORCED / OFF;
  • rows 6 and 7: the watchdog symbol (blinks each second), the sensor (T1, T2...) and the unit (kWh, °C). The value is written again only when it changes: the I2C transfer of the large digits takes about 20 ms in the loop.

inline

Shows item item of the turn on the OLED, once per second.

Parameters
itemwhat to show (Display::itemAt())
energyWhthe diverted energy, in Wh
temperature_x100the temperature of the item, for TEMPERATURE

Only what changed goes over I2C (about 20 ms for the 5 large digits at 400 kHz, longer with the ADC interrupt): the labels when the item changes, a large digit when it differs from the one shown. The large digits fill rows 0 to 5 of columns 0 to 14 with their background, so they write over whatever was there.
