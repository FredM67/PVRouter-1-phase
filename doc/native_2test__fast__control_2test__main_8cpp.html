Detailed Description

Native unit tests for fast_control.h: the decision on the predicted energy.

At the first sample set of the negative half cycle, the energy at the end of the cycle is predicted: the bucket at the start of the cycle plus the energy of the first half, scaled to a whole cycle (Robin's fasterControl). The decision, a few sample sets later, is taken on that prediction only. No config.h, no stubs: the real code.

template<uint8_t NMin, uint8_t NMax, uint8_t SumShift>
static void checkDivisionFree ( const float cal,
const uint8_t samplesPerCycle )
static

Every in-range n gives the division form, within the rounding of the table.

The ISR's former prediction: the first half through the table entry for a whole cycle (samplesPerCycle sample sets), then x samplesPerCycle / n. The division-free form: 2 x the first half through the entry for 2n sample sets, 2 x sumP x cal / 2n. Both round: the entries to 16 bits, contribution() to the unit, the division by truncating.
