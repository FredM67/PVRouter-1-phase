◆ printCt1Calibration()

template<bool newBoard>
void printCt1Calibration ( )
inline

Print the power calibration of CT1 (grid) as calibration.h has it.

The new board: f_ctRating and f_powerCalPerAmp; the old boards: f_powerCalOldBoard. The f_powerCal the router computes from them is not printed: what can be checked is what was typed. A template, so that each build compiles only its board's branch (its strings included).

Template Parameters
newBoardwhether the router runs with the new board's calibration

◆ printCt2Calibration()

template<bool ct2, bool newBoard>
void printCt2Calibration ( )
inline

Print the power calibration of CT2 (diverted energy) as calibration.h has it, when CT2 is fitted.

The new board: f_ctRatingDiverted (f_powerCalPerAmp is CT1's, printed before); the old boards: f_powerCalDivertedOldBoard. A template, so that a build without CT2 compiles none of it.

Template Parameters

newBoardwhether the router runs with the new board's calibration
