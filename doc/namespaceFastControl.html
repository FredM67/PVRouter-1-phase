The energy in the bucket predicted at the end of the mains cycle.

The bucket at the start of the cycle plus the energy of the first half scaled to a whole cycle: the average power as one cycle's energy, as Robin's energyInBucket_long + averagePower.

Parameters
bucketThe bucket level at the start of the cycle, in bucket units.
energyFirstHalfThe energy of the sample sets so far, in bucket units, converted as a whole cycle's contribution of samplesPerCycle sample sets.
samplesFirstHalfThe number of sample sets so far.
samplesPerCycleThe number of sample sets of a whole cycle that energyFirstHalf was converted for.
Returns
bucket + energyFirstHalf x samplesPerCycle / samplesFirstHalf (integer division, truncated towards 0), or bucket when samplesFirstHalf is 0.
Precondition
|energyFirstHalf| x samplesPerCycle fits in an int32_t (the caller checks its range at compile time).

The energy in the bucket predicted at the end of the mains cycle, without a division.

As predictEndOfCycle() above: bucket + sumP x cal / n, through the table entry of wholeCycleIndexOf(), with the same rounding as the bucket's own contributions.

Parameters
bucketThe bucket level at the start of the cycle, in bucket units.
sumFirstHalfThe sum of the sample sets so far (V_ADC x I_ADC), at most nMax / 2 x 2^18.
calOfTwiceThe table entry wholeCycleIndexOf() gives.
sumShiftThe shift of the sums the table was built for (SumShift of toFixedPerSample()).
calShiftThe shift of the table.
Returns
The predicted bucket level.

uint8_t FastControl::wholeCycleIndexOf ( const uint8_t samplesFirstHalf,
const uint8_t nMin,

constexpr

The entry of the per-sample calibration table that turns the first half into a whole cycle's energy without a division.

The entry for n sample sets holds cal / n (Energy::toFixedPerSample()): the entry for 2n, applied to 2 x sumP, gives sumP x cal / n, the first half's average power as one cycle's energy, which predictEndOfCycle() above computes with a division.

Parameters
samplesFirstHalfThe number of sample sets so far, n.
nMinThe smallest number of sample sets of the table (N_MIN).
nMaxThe largest number of sample sets of the table (N_MAX).
Returns
2n - nMin when nMin <= 2n <= nMax, NO_INDEX otherwise (no proper half cycle).

The sample set of the negative half cycle at which the loads are decided.

Counted from 0 at the first sample set of the negative half, as Robin's sampleSetsDuringNegativeHalfOfMainsCycle == POST_ZERO_CROSSING_MAX_COUNT (3): the voltage is then far enough past the zero crossing for the triac drivers to be armed reliably.
