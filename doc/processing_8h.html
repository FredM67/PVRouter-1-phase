◆ rescaleToNMin()

int32_t rescaleToNMin ( const int32_t sumP,
const uint8_t n )

Rescales the sum of a cycle of an unexpected length to N_MIN sample sets.

A call of its own: its division keeps its registers out of the contribution task, which runs it on an unexpected cycle length only (start-up, missing mains).

Parameters
sumPThe sum of the cycle.
nIts sample sets, not 0.
Returns
(sumP / n) x N_MIN
