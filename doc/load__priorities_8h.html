Detailed Description

The load priority state machine: which load to switch at each mains cycle.

Each element of the priority array is one logical load, the highest priority first: its low 7 bits are the physical load number (an index of physicalLoadPin[]), its high bit says whether the load is ON.

Once per mains cycle, the ISR compares the energy bucket with two thresholds: above the upper one, the first load OFF in priority order comes ON; below the lower one, the last load ON goes OFF. After a switch, no other load may switch for POST_TRANSITION_MAX_COUNT cycles, so that the switch has time to show in the bucket: only the load just switched may switch back. The threshold follows the bucket meanwhile.

A threshold goes back to its default only when the bucket is in the other half: while the bucket stays in the upper half, the upper threshold keeps the level the bucket reached during the last post-transition period, and a load comes ON only if the bucket rises above it. The same for the lower threshold in the lower half.

Then the logical states give the physical ones: a load is ON if its override is active, or if diversion is enabled and its logical state is ON. Calibration mode keeps every load OFF.

Note
This header has no Arduino dependency, so it can be exercised by the native test suite. Everything runs in the ADC ISR: the functions are forced inline, except Switching::onNewCycle() (see there).
