bool check_boost_windows ( )
constexpr

Every scheduled boost lies within the off-peak period and lasts: otherwise, it never runs (LAST(HOURS(9)) with 8 hours, FOR(MINUTES(0))), or the meter cuts it short (FIRST(HOURS(10)) with 8 hours).

Note
All these checks are done by the compiler. It does not take ANY space in the Arduino.

◆ targetsAreRemoteLoads()

template<typename List>
bool targetsAreRemoteLoads ( const List & list)
constexpr

Each REMOTE_LOAD(n) target of an entry of list must be an existing remote load.

REMOTE_LOAD() counts from 0: with two remote loads, REMOTE_LOAD(2) is a third one that does not exist, and the entry would force nothing. From 8 on, REMOTE_LOAD() gives pin 0 (the masks hold 8 remote loads): targetsAreOutputs() rejects it.
