Detailed Description

Embedded tests for teleinfo.h: the IoT frame on the ATmega328P (16-bit int)

The code of the firmware, run on the target: the lines (digits of 16- and 32-bit values, checksum) and whole frames written step by step, with and without the diverted power and energy (D and E). The expected text is built independently, its checksums summed by appendLine(). The native tests (test/native/test_teleinfo) check the frame byte for byte against the buffered frame of the former firmware.
