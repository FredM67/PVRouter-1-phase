Detailed Description

The display, without Arduino: its pins, what it shows when, and the text it shows.

From Mk2_fasterControl_Full (utils_display.h, utils_oled.h). Nothing here depends on a setting or on Arduino, so the native tests build it on the PC. utils_display.h drives the display with it.

  • The pins of each display type, as a list and as a mask, for the pin checks.
  • The port image of each character of the 7-segment display: the loop turns the 4 characters into 4 images, and the ADC interrupt only writes one of them to the ports every few ms (no table look-up, no per-pin write in the interrupt).
  • What is shown in turn: the energy slot (FORC, OFF, the diverted energy, or the walking dots while nothing was diverted since the last reset), then each temperature.
  • The characters of the 7-segment display and the text of the OLED for a value.
