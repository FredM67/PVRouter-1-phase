Detailed Description

Native tests for teleinfo.h: the IoT frame, streamed a line per step.

The frame is written by TeleInfo::writeFrameStep(), one line per step of the serial output (STX before the first line, ETX after the last), from a data source: here, test sources with every feature set of the firmware. It must give, byte for byte, what the buffered TeleInfo class of the firmware wrote before (Reference below, its code kept as it was, utoa()/ultoa() replaced by snprintf()), with the diverted power and energy (D and E) sent after P when CT2 is fitted.
