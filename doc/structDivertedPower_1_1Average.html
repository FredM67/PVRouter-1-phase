Detailed Description

Division by the number of cycles of the datalog period, as a fixed-point product.

watts() computes ((sum >> preShift) x factor) >> (8 + postShift): a 24 x 16 bit multiplication (multU24x16_to32_hi8(), ~30 cycles on AVR) instead of a 32-bit division (~600 cycles), in the ISR.
