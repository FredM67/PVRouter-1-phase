Detailed Description

Native tests for adc_chain.h: the analog inputs, the reference and the ADMUX pipeline.

Three channels, sampled in a fixed chain V -> I_GRID -> I_DIVERTED. The ADC runs free: when the ISR of a finished conversion runs, the next conversion has already started with the previous ADMUX, so the ADMUX written now applies to the conversion after next. The pipeline test plays this out and checks that the channel really converted is the one the ISR believes it handles, on each board.
